# Prompt Templates

Use these as starting points for concept generation. Generate `front`, `back`, `left`, and `right` turnaround sheets against a neutral background.

## Master style prompt
`Toy tabletop American football character, chunky helmet, miniature plastic figure proportions, premium sports board game aesthetic, broadcast readability, clean silhouette, layered shapes for modular game art, strong base shadow, high detail but simplified forms, no background, orthographic turnaround sheet`

## QB
`Elite quarterback tabletop figure, balanced athletic build, command posture, sleek facemask, readable jersey paneling, modular layered parts, front/back/left/right turnaround`

## Skill player
`Wide receiver or running back tabletop figure, explosive athletic proportions, lighter pads, clean limb separation, modular game art layers, front/back/left/right turnaround`

## Heavy body
`Tight end or offensive lineman tabletop figure, broad chest, heavier lower body, larger shoulder pads, modular layered parts, front/back/left/right turnaround`

## Front-seven defender
`American football pass rusher tabletop figure, aggressive stance, strong shoulder silhouette, modular layered parts, front/back/left/right turnaround`

## Defensive back
`American football cornerback or safety tabletop figure, lean reactive silhouette, tighter pads, modular layered parts, front/back/left/right turnaround`

## Negative prompt
`photorealistic, muddy details, dynamic perspective, dramatic background, motion blur, full scene, painterly brushstrokes, extra limbs, asymmetrical turnaround, text, watermark`
